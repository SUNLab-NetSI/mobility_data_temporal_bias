# mobility_data_temporal_bias

Data and code supporting the paper: "Correcting temporal bias in mobility data using time-use surveys" by S. A. Sanchez, et. al.

## Overview

* `data/` contains the processed mobility data and time-use survey data used in the analysis.
* `scripts/` contains the code used to process and transform the time-use survey data to re-weight mobility data, and the code to reproduce the paper's figures.
